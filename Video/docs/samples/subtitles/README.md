# Subtitle Samples

`sample.srt` and `sample.ass` are minimal sidecar fixtures for manually validating 013A.

To use one, copy it beside any local video and rename it to the video's base name:

```text
movie.mp4
movie.srt
```

The samples cover timed display, multiline cues, and ASS override-tag stripping. They do not require a specific video file.
