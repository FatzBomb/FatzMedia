# Stage Update

Stage: 004B — Release-Visible Diagnostics
Date: 2026-07-06

## Changed

- Added public `MediaDiagnosticLevel` enum (`Api/MediaDiagnosticLevel.cs`) with 3 levels: Info, Warning, Error.
- Added public `MediaDiagnosticEventArgs : EventArgs` (`Api/MediaDiagnosticEventArgs.cs`) carrying Level, Category, Message, SourcePath, InnerException.
- Added `event EventHandler<MediaDiagnosticEventArgs>? MediaDiagnostic` to `IMediaControlSession` and `MediaControlPlayer`.
- Added internal static `DiagnosticRouter` class (`Core/DiagnosticRouter.cs`) with `Raise(level, category, message, ...)` method — a static event sink that lets any engine component raise diagnostics without coupling to the public API.
- Added internal `MediaDiagnosticInfo` record (`Core/MediaDiagnosticInfo.cs`) as the internal payload.
- `MediaControlPlayer` subscribes to `DiagnosticRouter.DiagnosticOccurred` in constructor and re-marshals to the public `MediaDiagnostic` event through `MediaControlOperationQueue`. Unsubscribes in `Dispose`.
- Instrumented 23 engine/pipeline files with `DiagnosticRouter.Raise(...)` calls alongside existing `Debug.WriteLine(...)` — 121 insertions total, zero removals.
- Added `MediaDiagnosticEventArgsTests` (4 tests) covering construction, null handling, and level round-tripping.
