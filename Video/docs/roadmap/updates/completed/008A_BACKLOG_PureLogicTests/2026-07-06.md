# Stage Update

Stage: 008A — Pure Logic Tests
Date: 2026-07-06

## Review conclusion

Stage is a backlog stage that adds automated tests for pure logic with no
native/GPU/WPF dependencies. It is safe to promote early because it does not
disturb runtime behavior. The candidate areas (CDG state machine, sidecar
resolver, AudioPresentationClock math, MediaState transitions, FileTypes) are
all present in the current code and cleanly testable. "Seek acceptance and
timing helper logic" was deferred — `NormalizeSeekTarget` is a private method
on `PlaybackCoordinator` and not separable without a production refactor, which
is outside this stage's scope.

## Changed

- Added new test project `FatzBombMedia.MediaControl.Tests` (xUnit, net10.0-
  windows7.0, x64) and added it to the solution.
- Added `<InternalsVisibleTo Include="FatzBombMedia.MediaControl.Tests" />` to
  `FatzBombMedia.MediaControl.csproj` so internal pipeline/Cdg types are
  testable. Non-behavioral; does not affect the NuGet package output.
- Extracted `NormalizeSeekTarget` from `PlaybackCoordinator` (private) to
  `SeekHelpers.NormalizeSeekTarget` (internal static pure method in new
  `Pipeline/SeekHelpers.cs`). `PlaybackCoordinator.Seek` delegates to it. No
  behavior change.
- Added 108 tests across 7 test classes:
  - `CdgStateMachineTests` — MemoryPreset fill/no-fill, BorderPreset, TileBlock
    Normal/Xor, ScrollPreset, LoadColorTable, DefineTransparentColor, snapshot
    dirty-region consumption, background override/opacity, packet rejection.
  - `CdgDirtyRectTests` — ClampToFrame bounds/empty/zero-area, FullFrame, Empty.
  - `FileTypesTests` — Archive/Image/Cdg extension matching, case-insensitivity,
    Audio/Video sets empty before Bootstrap.
  - `MediaStateTests` — SetOpened/SetPlaybackState/SetPosition/SetDuration/Reset,
    equality short-circuits, duration clamps position, CleanSeconds.
  - `AudioPresentationClockTests` — not-running path (clean/clamp), running path
    (hard correction reanchor, clamp, monotonic), Start/Pause/Reset.
  - `MediaBackgroundResolverTests` — content-flag rules (null/video/image/none
    → null), sidecar image/video resolution, base-name matching, case-insensitive
    extension, archive path delegation (uses temp files, no mocking of engine).
  - `SeekHelpersTests` — NormalizeSeekTarget clamp, clean, non-finite, negative,
    zero-duration pass-through.
